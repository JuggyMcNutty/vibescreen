# VibeScreen `0.0.21.beta_test`

Тестовый пакет для Creality K1 и K1 Max. Это Beta Test, не стабильный релиз.
Пакет опубликован как GitHub prerelease `0.0.21.beta_test` и не входит в
стандартный канал обновлений `latest`.

## Что проверять

- Русскую локализацию и отображение кириллицы в интерфейсе, особенно в
  подтверждении аварийной остановки.
- Центрирование заголовка «Подсветка» и подписи режимов bed mesh.
- Две оценки ETA одновременно: по прогрессу файла и по метаданным слайсера.
- Удаление G-code долгим нажатием на 3D-превью с явным подтверждением.
- Индикацию температур при изменении target. В simulator температура
  поднимается/опускается по fake-модели; на принтере нагревом управляет Klipper.
- Работу интерфейса во время загрузки крупных G-code-файлов и теста ремней.

## Известные наблюдения

При загрузке G-code-файла размером около 40 МБ экран в тесте исходного форка
погас и перестал реагировать на касания. Печать продолжилась и завершилась
нормально, после чего работоспособность экрана восстановилась. Причина пока не
подтверждена, поэтому этот дефект нельзя считать исправленным.

В другом тесте ремней на оси B CSV-файл записывался на хост, после чего
интерфейс зависал. Нужны повторное воспроизведение и журналы.

## Установка и восстановление

Скачайте файлы Beta из GitHub prerelease `0.0.21.beta_test`, скопируйте их
каталог на принтер в `/usr/data/guppyscreen-beta/` и запустите:

```sh
cd /usr/data/guppyscreen-beta
sh install-beta.sh
```

Скрипт устанавливает приложенный архив локально. Beta не заменяет стандартный
`latest`; обычное обновление сохраняет эту тестовую версию, пока явно не задан
`--force`.

Установщик автоматически сохраняет текущую папку VibeScreen (`/usr/data/guppyscreen`) перед заменой в
`/usr/data/guppyify-backup/guppyscreen-original.tar.gz` и проверяет архив.
Если копию нельзя создать или проверить, установка прекращается до замены
программы. При повторных обновлениях исходная копия не перезаписывается.

Чтобы вернуться к сохранённой версии, запустите на принтере:

```sh
/usr/data/restore-guppyscreen.sh
```

Скрипт проверит архив, сохранит установленную сейчас VibeScreen в отдельную
копию, остановит экран, восстановит исходную папку и запустит экран снова.
Обновлятор, настроенный на репозиторий `Vasinok/vibescreen_ru`, при этом
сохраняется.

Резервная копия включает папку VibeScreen и её конфигурацию. Она не является
снимком прошивки принтера и не откатывает отдельные файлы Klipper или системные
сервисы, установленные вне этой папки. Beta может содержать ошибки; резервная
копия снижает риск, но не гарантирует, что любой сбой будет автоматически
исправлен.

Для проверки интерфейса без принтера запустите `tools/run-simulator.sh` из
корня проекта.

G-code-файла и момент возникновения. Приложите журналы VibeScreen и
