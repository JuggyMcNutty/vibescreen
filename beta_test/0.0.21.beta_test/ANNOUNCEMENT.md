# Черновик объявления

Отдельный пакет Beta Test VibeScreen `0.0.21.beta_test` для Creality K1 и K1
Max собран в `beta_test/0.0.21.beta_test/`. Это папка с локальным архивом и
установочным wrapper, не GitHub Release и не обновление через `latest`. В тест входят русская локализация,
кириллический шрифт для диалогов, две оценки ETA, удаление G-code с
подтверждением и динамическая температура в simulator.

Известно о двух проблемах, которые требуют внимания тестировщиков. В одном
случае при загрузке G-code-файла около 40 МБ экран погас и перестал реагировать
на касания, хотя печать продолжилась и завершилась. В другом тесте ремней на
оси B после записи CSV-файла зависал интерфейс. Причины пока не установлены.

Перед заменой установленной папки программа сама создаст и проверит резервную
копию. Если это не удастся, установка остановится. Для возврата к сохранённой
версии предусмотрена команда `/usr/data/restore-guppyscreen.sh`; детали и
ограничения описаны в README пакета.

Установочный wrapper находится в `beta_test/0.0.21.beta_test/`. После
копирования всей папки на принтер запускать `sh install-beta.sh` из root shell.
В отчёте о тесте укажите модель и прошивку принтера, версию Beta, размер файла
и приложите журналы без API-ключей и паролей.
